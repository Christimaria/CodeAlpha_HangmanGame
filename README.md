# CodeAlpha Hangman Game

## Project Overview
This project is a simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

The player must guess a randomly selected word one letter at a time. The player is allowed a maximum of six incorrect guesses.

## Features
- Random word selection from a predefined list.
- Letter-by-letter guessing.
- Displays correctly guessed letters and hidden letters.
- Limits incorrect guesses to six.
- Checks for repeated guesses and invalid input.
- Displays win and game-over messages.

## Technologies Used
- Python 3
- Random module
- Loops and conditional statements
- Lists and strings
- User input and output

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python hangman.py
```
